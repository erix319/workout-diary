# Workout Diary

A simple interactive workout tracker built with HTML, CSS, and JavaScript. It lets you log running, cycling, skiing, and swimming workouts on an interactive map, then saves them in local storage for later review.

## Features

- Add workouts directly on the map
- Track distance, duration, and pace
- Save workouts locally in the browser
- Reset stored workouts at any time
